Attention Residuals — Softmax Attention Over Depth

Paper: Attention Residuals — Kimi Team (Moonshot AI), arXiv:2603.15031 · code. Technical report, March 2026.

✅ Conclusion

  • The move: a residual connection is a uniform sum over all earlier layer outputs. Replace it with softmax attention over depth so each layer picks which earlier layers it wants.
  • Why it works: softmax weights sum to 1, so the hidden state stops growing — that kills PreNorm dilution. And the weights are input-dependent, so a layer can reach back selectively.
  • The cost trick: Full AttnRes needs O(Ld) memory and cross-stage communication, which breaks under pipeline parallelism. Block AttnRes groups layers into N≈8 blocks and attends over block summaries → O(Nd), recovering nearly all the gain.
  • Result: matches a baseline trained with 1.25× more compute; 48B/3B-active model on 1.4T tokens improves on every downstream benchmark (GPQA-Diamond +7.5, Math +3.6, HumanEval +3.1).
  • The ablation that carries the paper: DenseFormer also gives every layer access to all previous outputs, but with fixed coefficients — and it scores 1.767 vs baseline 1.766, i.e. nothing. Cross-layer access is not the contribution. Input-dependence is.

📄 Paper Summary

The problem: PreNorm dilution

A standard PreNorm block is h_l = h_(l-1) + f_l(Norm(h_(l-1))). Unroll it:

h_L = h_0 + f_1(...) + f_2(...) + ... + f_L(...)

Every layer's output is added with weight exactly 1. Not learned, not input-dependent. Three things follow, and the paper names all three:

  • Output growth. You add L things and never divide, so ‖h_l‖ grows as O(L). Nothing regulates it — hence "uncontrolled".
  • No selective access. Every layer reads the same pre-mixed blob h_(l-1). An attention layer and an MLP layer get identical input even though they might want different weightings.
  • Irreversible loss. Whatever the sum squashes cannot be dug back out later.
The feedback loop that makes it worse. Layer l reads Norm(h_(l-1)) — normalized, so always the same scale no matter how big the stream got. So its natural output stays around size 1. But 1 out of 60 is nothing. The only way a deep layer can matter is to learn to emit much larger outputs — and large activations are exactly what destabilizes training. The idea: depth is just another sequence

Residual connections compress everything before layer l into one state — exactly what an RNN does over time. Attention fixed that for sequences. This paper does the same fix for depth.

flowchart LR subgraph Standard["Standard residual — uniform sum"] S1[v0] --> SS[h_l] S2[v1] --> SS S3[v2] --> SS S4[v3] --> SS end subgraph Attn["AttnRes — softmax over depth"] A1[v0] -->|a0| AA[h_l] A2[v1] -->|a1| AA A3[v2] -->|a2| AA A4[v3] -->|a3| AA end 
before:  h_l = v_0 + v_1 + ... + v_(l-1)                      all weights = 1
after:   h_l = a_0·v_0 + a_1·v_1 + ... + a_(l-1)·v_(l-1)      weights sum to 1

The weights come from softmax attention: a_(i→l) = softmax_i( w_l · RMSNorm(k_i) ), where

  • query q_l = w_l — one learned d-dimensional vector per layer. Not computed from the input.
  • key = value k_i = v_i = f_i(h_i) — the actual layer outputs, which are input-dependent.
  • the RMSNorm on keys stops a layer with big-magnitude outputs from hogging the attention weights.

All pseudo-queries w_l must be zero-initialized. That makes every score 0, so softmax gives uniform weights and AttnRes starts as an equal-weight average of previous layers. The paper reports that non-zero init caused training volatility. Cost per layer is one RMSNorm and one d-dimensional vector — negligible against total parameters.

Cost is O(L²d) arithmetic and O(Ld) memory per token. Since depth is small (L < 1000, unlike sequence length which hits millions), O(L²) over depth is cheap.

Block AttnRes — the part that makes it shippable

In plain training, Full AttnRes is nearly free: the layer outputs it needs are already kept around for backprop. At scale it breaks, because real training uses activation recomputation (those activations were supposed to be freed) and pipeline parallelism (every layer output must now cross stage boundaries). That O(Ld) communication is the killer, and local batching can't fix it.

Block AttnRes partitions L layers into N blocks. Inside a block, outputs are summed the normal way. Across blocks, full softmax attention runs over just the N block summaries plus the token embedding. Memory and communication drop to O(Nd), compute to O(N²).

N = 1  →  standard residual connection
N = 8  →  the sweet spot (recovers most of the gain)
N = L  →  Full AttnRes

Gains concentrate on multi-step reasoning and code — consistent with the story that better depth-wise flow helps compositional tasks, where late layers want to build on specific earlier representations.

Training dynamics. The baseline's output magnitude climbs monotonically with depth. Block AttnRes shows a bounded sawtooth — selective aggregation at each block boundary resets the accumulation. Gradients also spread out: the baseline piles disproportionately large gradients into the earliest layers, while the softmax forces sources to compete for probability mass.

The unified view (§6)

Write any residual scheme as a depth mixing matrix M, where M_(i→l) is how much of layer i's output reaches layer l. Then:

SchemeM looks like
Standard residualall-ones lower triangular — rank 1, fixed
Highway1-semiseparable — same rank, but input-dependent
(m)HC / mHCm-semiseparable — state expansion along depth
Full AttnResdense, rank L
Block AttnResrank between N and N+S

The punchline: every prior residual variant is depth-wise linear attention. AttnRes is depth-wise softmax attention — the same linear→softmax transition that transformed sequence modeling, now applied to depth.

Overhead: <4% end-to-end training under pipeline parallelism, <2% inference latency. It needs cross-stage caching (each block stored once across virtual stages) and a two-phase inference strategy using online softmax.
